# Instrukcja Uruchomienia Projektu


## Wymagania Wstępne
1. System operacyjny:
   - Windows
   - Unix 
2. Zainstalowany Python w wersji 3.12 lub wyższej.
   - W przypadku systemów Ubuntu/Debian wymagana jest instalacja narzędzia `python3.12-venv`.
3. Dostęp do przeglądarki internetowej.


## Uruchomienie na Systemie Windows
1. Otworzyć konsolę systemową (CMD lub PowerShell).
2. Przejść do głównego katalogu projektu:
    ```bash
    cd <ścieżka_do_katalogu_projektu>
    ```
3. Wykonać polecenie:
    ```bash
    ./scripts/start.bat
    ```

## Uruchomienie na Systemie Unix
1. Otworzyc konsolę bash.
2. Przejść do głównego katalogu projektu:
    ```bash
    cd <ścieżka_do_katalogu_projektu>
    ```
3. Wykonać polecenie:
    ```bash
    ./scripts/start.bash
    ```

## Po uruchomieniu skryptu
1. Jeśli program został poprawnie zainicjalizował projekt, w oknie konsoli pojawi się link do serwera Jupyter Notebook.
    ```bash
    http://127.0.0.1:8888
    ```
2. Otworzyć link w przeglądarce internetowej.
3. W interfejsie Jupyter Notebook otworzyć plik `fornagiel_miklas_projekt.ipynb`
4. Alternatywnie, otworzyć główny plik projektu, korzystając z linku:
    ```bash
    http://127.0.0.1:8888/notebooks/fornagiel_miklas_projekt.ipynb
    ```
